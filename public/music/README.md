# AmiRa V6 music

The player uses openly licensed / public-domain Indian and atmospheric tracks rather than copyrighted Bollywood recordings.

## Included sources

- **Electronic Indian tabla tune** — OpenGameArt, CC0 / public domain.
- **Starfield Romance** — Yoiyami, OpenGameArt, CC0 1.0 Universal.
- **More Hindi/Indian royalty-free options** — Pixabay Hindi Romance / Bollywood collections. Review the individual track license before adding any track to a deployed build.

The app intentionally does not bundle commercial Hindi film songs. Browser autoplay is not bypassed: audio starts from an explicit user play action, and the app handles playback failure gracefully.
